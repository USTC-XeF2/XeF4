```

```

消息列表中的最后一条为新消息，前文都是历史消息。成员标识包含 `owner` 与 `admin` 两种，分别代表群主和群管理员，普通成员没有标识。如果一条消息引用了前文的消息，则会有额外的引用内容摘要，引用的完整消息内容也会包含在历史消息中。消息中可能包含类似 `[图片:xxx]` 的标识，其中的内容是图片中提取出的文字。历史消息中可能包含你自己的消息，依据成员名称进行判断。

- `reason`：做出此判断的简短原因
- `desire`：一个 0-10 间的整数，代表回复新消息的欲望值
